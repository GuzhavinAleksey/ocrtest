# Выбранные страницы PDF → PNG → Qwen → JSON

Требуется Node.js 24+ и `npm ci`.

## Только конвертация

Укажите PDF, номера страниц и папку результата:

```bash
npm run convert -- report.pdf 11-19 output
npm run convert -- report.pdf 11,12,15-16 output
```

Нумерация с **1**, как в PDF-просмотрщике. Конвертируются только указанные страницы; создаются `page-11.png`, `page-12.png` и т. д. Для присланного отчёта МТС нужные страницы — `9-12`. Определение форм/текстовый слой не требуются, поэтому можно вручную выбирать и страницы сканированного PDF.

## Конвертация и передача модели

Задайте в окружении или локальном `.env`:

- `OPENAI_API_URL` — адрес вашего vLLM с `/v1`;
- `OPENAI_API_MODEL` — имя vision-модели (по умолчанию `Qwen/Qwen3.8-27B`);
- `OPENAI_API_KEY` — ключ, если сервер требует авторизацию. Для сервера без авторизации можно оставить пустым.

Секреты не добавляйте в коммиты.

```bash
npm run qwen -- report.pdf 11-19 output
```

Скрипт конвертирует выбранные страницы, последовательно отправляет **каждый PNG отдельным запросом** и объединяет ответы в `output/financials.json`. Результат также выводится в консоль:

```json
{
  "non_current_assets": 23339986338,
  "current_assets": 2396341798,
  "balance": 25736328136
}
```

Это сокращённый пример. Все **198 показателей из приложенного списка** перечислены в `src/indicator-codes.ts`; промпт автоматически содержит каждый английский ключ и его код. Названия используются точно из этого списка. Для баланса выбирается колонка на 31 декабря 2025 года, для результатов и денежных потоков — за 2025 год; для капитала — «Итого» соответствующей строки.

Отсутствующие на странице показатели модель должна пропускать. Нечитаемые значения и прочерки сохраняются как `null`, видимые нули — `0`. Обработчик принимает обычный JSON и JSON в Markdown-блоке, нормализует пробелы, скобки отрицательных чисел и десятичную запятую. Ключи-коды также преобразуются в английские имена. Противоречащие значения одного показателя на разных страницах вызывают ошибку; существующее число не заменяется `null`. Итоговый JSON записывается только после успешной обработки всех выбранных страниц. При ошибке предыдущий `financials.json` не обновляется; для разных документов используйте отдельные папки.

## Проверки

```bash
npm test
node_modules/.bin/tsc --noEmit --strict --esModuleInterop --skipLibCheck --target ES2020 --module commonjs --ignoreConfig src/qwen.ts src/convert.ts
```

Проверяются выбор страниц, все ключи словаря, обработчик JSON, объединение результатов и реальная конвертация PDF с подменённым клиентом модели. Реальное распознавание через vLLM в облаке не проверено: ваш сервер недоступен из этой среды.
